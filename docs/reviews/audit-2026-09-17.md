## Prosedur keluaran seterusnya

- Semak dan commit senarai fail yang eksplisit, termasuk aset runtime untracked yang diperlukan. Jangan stage draf, rahsia atau keadaan CLI Supabase.
- Push commit yang diluluskan; jalankan `E2E_HEADLESS=0 npm run release:verify` dari checkout bersih.
- Terbitkan commit yang sama. Jika pakej terasing diperlukan, hasilkan daripada `git archive HEAD`, bukan salinan working tree. Pastikan `.vercelignore` digunakan untuk kandungan deployment.
- Rekod SHA sumber, deployment ID, status READY, semakan URL live dan sasaran rollback berserta SHA. Lulus lokal atau push bukan bukti produksi.
